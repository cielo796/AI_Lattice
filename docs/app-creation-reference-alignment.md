# アプリ作成画面の参照実装への再調整

対象: `/apps/new/ai`。確認日: 2026-10-06。作業ブランチ: `codex/performance-optimization`。

添付 `ai-lattice-app-creation/SPEC.md`、`screenshots/`、`reference/demo.html`、`reference/field-builder.js` を比較し、画面構成・密度・操作を参照実装に近づけた。添付のコーラル配色ではなく、今回の依頼を優先して既存のグローバル配色を維持する。`navy` / `white` / `dark` のトークンや共通サイドバーは変更していない。

## 変更内容

- 説明画面: 1000文字の入力欄、横並びのヒントと文字数、構成の注記、使用モデルと生成操作、5つの短い入力例をコンパクトに配置。入力例は文章の挿入だけで、置き換えは確認する。
- 生成中: 4段階の表示とフォーム形のスケルトンを1枚のパネルに統合。経過時間からの目安であることを明記し、未取得のアプリ名等を実際の生成結果として表示しない。中断後の遅着応答は反映しない。
- 設計画面: アプリとテーブルの名前・コード、元の説明、モデルの決定元を上段に配置。説明とAIの設計説明は展開して編集・確認できる。自動／手動コードの表示と、保存時と共通の形式検証を追加。
- ビルダー: 左224px・中央可変・右320pxの3列。部品、AI候補、型別の入力モック、AI印、設定、作成内容を参照構成に合わせる。1280px未満は設定ドロワー、640px未満は2列の項目も縦に表示する。
- 操作: 既存のPointer Eventsによるドラッグ・タッチ・キーボード配置を維持。支援技術によるクリックでも追加でき、通常のクリックは二重追加しない。削除時は近くの項目を選択する。
- 日本語入力: 選択肢のIME変換確定Enterをタグ追加と混同しない。変換後や貼り付けの区切り入力を正規化する。
- フッター: AI調整入力と差分確認を一体化。EnterとCtrl/Cmd＋Enter、再生成、下書き作成を配置。差分は適用前と明記し、変更がない場合は適用できない。AIの説明や候補だけの変更も差分に含める。
- フォーカス: 項目追加時の名前欄へのフォーカスとドロワー表示を描画前に完了させる。遅延したフォーカスが、直後のカード選択やAlt＋矢印操作を奪う競合を修正。
- 失敗時: 生成・調整・保存のエラーで入力や編集内容を失わず、保存失敗時は編集ステップに戻る。
